2Put the token in your environment

Every snippet below reads BRIEFD_TOKEN, CONFLUENCE_EMAIL and CONFLUENCE_TOKEN (your Atlassian account email and an Atlassian API token) from the environment, so no secret ends up in a config file or in git.

macOS / Linux

Add the lines to ~/.zshrc or ~/.bashrc. Editors started from the Dock or a launcher do not read that file: start them from a terminal (code ., cursor .), or on macOS also run the launchctl setenv lines and restart the editor.

Windows (PowerShell)

setx stores the variable for new processes: close and reopen your terminal and editor afterwards.

Something is not working

  • 401 / unauthorized — the token variable is empty in the editor's environment (it was started from the Dock, or before you set it). Restart the editor from a terminal. Some tools send ${BRIEFD_TOKEN} literally when the variable is missing.
  • The server is listed but the agent never calls it — the chat is not in Agent mode (Copilot, Visual Studio), the tools are switched off in the tools picker, or the instructions from step 4 are missing.
  • The server does not show up at all — the config is in the wrong file for your tool or editor mode (see the Copilot notes), or the folder is not trusted yet.
  • Connection refused or timeout — check the URL above opens from your machine (health check); a VPN or proxy may be required.
  • Confluence tools missing — they appear only when the server has Confluence configured; Confluence errors such as 401 mean your Atlassian email or API token is wrong.
